# 안녕하세요! AI의 이론과 서비스를 연결하는 엔지니어입니다. 👋

<br>

저는 딥러닝 논문의 핵심 아이디어를 직접 구현하고, 실제 서비스로 만들어내는 개발 경험을 보유한 AI 엔지니어입니다.

- AI 에이전트 개발 및 비전 모델에 관심이 많습니다.
- RAG 기술을 활용한 복잡한 도메인의 문제를 해결하는 프로젝트를 주도했습니다.
- Docker, AWS를 통해 실제 사용 가능한 서비스로 배포하고 운영한 경험을 중요하게 생각합니다.
